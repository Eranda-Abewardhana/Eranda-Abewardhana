### 02 / GENOMIC VARIANT PREDICTION
**Explainable Deep Learning for Genomic Sequence Analysis**

<p>
  <img src="https://img.shields.io/badge/Deep_Learning-PyTorch-EE4C2C?style=flat-square" />
  <img src="https://img.shields.io/badge/Transformers-2563EB?style=flat-square" />

  <img src="https://img.shields.io/badge/Explainable_AI-7C3AED?style=flat-square" />
</p>

A mutation-aware deep learning framework for predicting the pathogenic impact of genomic single-nucleotide variants.

**Engineering highlights**
- Dual-input REF/ALT sequence architecture.
- Multi-Scale CNN and Transformer Encoder.
- Mutation difference-learning mechanism.
- Approximately 714K ClinVar GRCh38 records.
- Integrated Gradients and In-silico Mutagenesis.
- **0.9465 ROC-AUC** on the held-out test set.
